# Horizonte.AdminUi.HorizonteSettings

Este es un módulo para el framework HorizonteNet.

## Descripción

Módulo Horizonte.AdminUi.HorizonteSettings que proporciona funcionalidades específicas dentro del ecosistema HorizonteNet.

## Estructura

- `PanelModulo.cs`: Clase principal del módulo que implementa la lógica de inicialización y comandos.

## Uso

Este módulo se carga automáticamente si está referenciado y configurado en la aplicación principal de HorizonteNet.
